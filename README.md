# Recipes

**两个人的私人菜谱与菜单，把自己做过的菜留下来，把「今天吃什么」变成一份可以买、可以做的清单。**

做过一道好吃的菜，下次不用再找视频、回忆用量。记录自己的食材、步骤和注意事项；选好这一餐想吃的菜后，按实际食材重量调整用量，再汇总需要购买的东西。

## 解决的问题

- **复做要重找教程。** 原视频还在，但实际用过的材料、改过的调味量和踩过的坑没有留下来。
- **会做的菜想不起来。** 想吃什么时缺少一份能看图、能选择的自家菜单。
- **采购要逐道算。** 同一种食材出现在几道菜里，需要合并数量，再排除家里已有的东西。
- **买到的重量不固定。** 菜谱写 1000g，不代表每次都能买到刚好 1000g，需要按本次实际重量换算。

## 产品原则

### 保存自己做的版本

原视频是参考来源，打开菜谱默认看到的是自己的完整做法。例如，把五花肉换成牛肉后，记录应成为自己的牛肉版，而不是每次阅读时重新对照和替换。

### 不确定的信息保持不确定

可以先保存草稿。没有确认的食材用量、火候和时间明确标记为待补充，不用推测填满一份看似完整的菜谱。

视频材料可以交给助手协助整理，再由本人校对。**第一版不承诺在网站内自动解析任意 Bilibili 视频。**

### 按这一次做饭来准备

支持半份、双份和按主食材重量换算；修改本次用量不改写原菜谱。有明确数值的配料可以换算，炖煮时间和「适量」不机械缩放。

### 买菜前核对，不维护库存

生成采购清单后手动标记家里已有的食材。这个状态只服务于本次采购，不要求每天记录冰箱里还剩多少东西。

## 第一版流程

1. **留下菜谱**：添加或编辑食材、用量、步骤、个人心得和成品照片，保留来源链接。
2. **看图选菜**：浏览自己的菜单，勾选「想吃」，再确定本次实际要做的菜。
3. **调整用量**：沿用菜谱基准，或按本次实际买到的主食材重量调整。
4. **准备采购**：合并同种食材，勾掉已有的东西，得到需要购买的清单。
5. **照着做，再补心得**：按自己的版本下厨，将这次的调整留给下次。

完整范围、边界和 15 项验收标准见 [PRD](./docs/PRD.md)。

## 成功标准

- 复做一份已经补完整的菜谱时，不需要重新搜索或观看教程。
- 女朋友可以独立看图选菜，本人能看到结果并确定这一餐做什么。
- 采购前从同一份菜单得到准确、经过已有食材核对的待买清单。
- 买到不同重量的主食材时，可以调整本次用量，无需重写整份菜谱。
